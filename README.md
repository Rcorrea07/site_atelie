# Site Atelie Sy Correa

Landing page para o Atelie Sy Correa, uma marca de costura criativa com bolsas, estojos, necessaires e pecas artesanais sob encomenda.

## Sobre

O site apresenta o atelie, destaca produtos artesanais, explica formas de pagamento e envio, e conduz a visitante para atendimento via WhatsApp.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- AOS para animacoes de entrada

## Como Rodar

Instale as dependencias:

```bash
npm install
```

Rode o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
